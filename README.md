-KQSHELL-
-This is a simple personal project of mine that is basically a custom made shell made from scratch on python my hand as a process to learn serious coding
-THIS PROJECT IS NOT INTENDED TO BE A PRODUCT AT ALL, IT MAY BE UNSTABLE BUT IT CAN BE DASILY DRIVEN FROM BASIC FUNCTIONS
-This shell can ONLY be used on linux and linux only, and its optimized best for arch and arch-based, and nixos
-HOW IT WORKS-
It is a simple python project which acts as a shell (e.g cmd, poweshell, bash, zsh, etc...) with some custom syntax which all can be viewed with the "help" command, this shell is powered by python and its builtin imports, therefore it is an extremly basic and very customizable shell to use.

#-Features-
- Here are the custom commands that can be used in kqshell and their explaination: 

         'kqshell.xdg.session' -> prints the current xdg session type
        'kqshell.xdg.desktop.session' -> prints the current xdg desktop session type
        'kqshell.shell.display.wayland' -> prints the current shell display type wayland
        'kqshell.xdg.desktop' -> prints the current xdg desktop type
        'kqshell.shell.display.x11' -> prints the current shell display type x11 
        'kqshell.shell.home' -> prints the current shell home directory
        'kqshell.shell.path' -> prints the current shell path
        'kqshell.primary.shell' -> prints the current primary shell
        'kqshell.kernel.ver' -> prints the current machine kernel version
        'kqshell.kernel.distro' -> prints the current machine distro name

        (These all will be in the "help" command)
